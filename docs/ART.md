# AtomicTux artwork

## Generated mascot

- Final asset: `assets/art/tux.png` (1254 × 1254 RGBA).
- Method: built-in `image_gen` tool, transparent background requested; no CLI/API fallback.
- Used directly for the title mascot, player sprites, roster portraits, and Android main icon.
- Character motion, identity rings, particles, arena tiles, crates, bombs, and UI are drawn in Godot.
- This is newly generated Tux-inspired penguin art. Tux, the Linux mascot, was originally created by Larry Ewing. No original Tux bitmap or classic game assets were copied into this repository.

Final generation prompt:

> Use case: stylized-concept. Asset type: transparent game character sprite for AtomicTux, an original open-source arcade bomb arena game. Primary request: one adorable little Linux Tux penguin, full body front view with a slightly elevated camera suitable for a top-down 2D arena. Glossy charcoal black body, creamy white belly and face, orange beak and large orange feet, confident playful expression, small teal scarf. Style: polished hand-painted 3D toy-like indie game art, crisp bold silhouette, soft lighting and subtle highlights, readable at 48 pixels. Centered character fills 85 percent of square canvas. Actual transparent background. No text, no logo, no scenery, no other objects, no ground plane, no cast shadow outside character. Both flippers visible.
